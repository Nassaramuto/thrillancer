# Implementation rules

- Follow the scoped plan; do not expand into tokenomics or mainnet gambling.
- Maintain a runnable app after each milestone and accurate STATUS.md.
- Never claim a preview is a live integration or simulated characters are real users.
- Use official docs, pinned compatible dependencies and a committed lockfile.
- Server authority for identity, allocation, results and receipts.
- Secrets stay server-side; never commit real .env files or private keys.
- Treat uploaded code and assets as untrusted. Reviewed registry controls publication.
- Do not overwrite reference exports. Keep reusable assets separate from cinematic choreography.
- Meaningful tests cover replay, authorization, room transition and payment accounting.
- Deployment and paid-provider setup are separate steps. Local implementation is authorized.
